## 脱敏与完整性

导出程序只读取列出的日志/结果、源码归档和 comparison.json，**不遍历私密备份**。宿主用户名、临时运行目录随机标识和合成安装目录标识被替换；总体结果中的私密备份地址改为省略说明。没有更改测试计数、状态、时间、断言、版本、镜像 ID 或源码哈希。源码快照保持原字节，其中测试代码的合成路径只是策略拒绝样例，不来自宿主配置。

私密备份、认证文件内容及哈希、shell 配置、聊天记录、SSH 文件、失败运行的混合日志没有上传。本机完整原件另行保留。公开 SHA256SUMS 标识脱敏后的文件字节，不能用它与未脱敏原件做字节相等比较。

在仓库根目录执行：

```sh
python3 scripts/verify_public_evidence.py
```

脚本验证公开材料哈希、实际通过标记、源码归档及其与当前 42 个被测文件的一致性。任何后续修改被测文件都会让这项历史对应检查失败，需要保留独立版本或创建新的证据目录。

材料是维护者提供的运行记录；哈希只能证明材料内部对应关系，不能替代第三方独立复现或数字签名。真实模型任务、真实账户和完整工具审批没有在容器中测试。模拟前端的退出码 17 是测试期望，整体测试容器退出码为 0。
